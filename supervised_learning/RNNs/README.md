# Recurrent Neural Networks (RNNs) from Scratch

## Project Overview

This project implements various recurrent neural network (RNN) components and architectures from first principles using Python and NumPy. The goal is to gain a deep understanding of how these sequence models—including simple RNNs, GRUs, and LSTMs—function and are trained.
