Transformer Machine TranslationThis project implements the full Transformer model architecture, as described in the paper Attention Is All You Need, for machine translation between Portuguese (PT) and English (EN).It covers the entire pipeline from dataset preparation and tokenization to model training, including custom masking and learning rate scheduling.🚀 Files and Implementation DetailsFileDescriptionKey Features3-dataset.pyDataset ClassLoads the ted_hrlr_translate/pt_to_en dataset, trains custom sub-word tokenizers, and sets up the optimized tf.data.Dataset pipeline. Includes filtering for max sequence length, caching, shuffling (buffer_size=20000), padded batching, and prefetching.4-create_masks.pycreate_masks functionGenerates the three required masks for the Transformer: Encoder Padding Mask, Combined Mask (Lookahead + Target Padding), and Decoder Padding Mask. Uses only TensorFlow operations.5-transformer.pyTransformer ArchitectureContains the complete model definition: MultiHeadAttention, EncoderBlock, DecoderBlock, Encoder, Decoder, and the main Transformer class. Includes positional encoding and residual connections.5-train.pyTraining PipelineDefines the custom learning rate schedule, implements sparse categorical cross-entropy loss (ignoring padding), sets up the Adam optimizer, and contains the train_transformer function with the required epoch and batch printing output.⚙️ Model Training & Optimization1. Learning Rate ScheduleA custom learning rate schedule is used, which is critical for stabilizing Transformer training:$$\text{lr} = \frac{1}{\sqrt{d_{model}}} \cdot \min\left( \frac{1}{\sqrt{\text{step}}}, \frac{\text{step}}{\text{warmup\_steps}^{1.5}} \right)$$This allows the learning rate to gradually increase during the initial warmup_steps (set to 4000) before decaying proportionally to the inverse square root of the step number.2. OptimizationOptimizer: AdamParameters: $\beta_1=0.9$, $\beta_2=0.98$, $\epsilon=1e-9$3. Loss Function and MetricsLoss: Sparse Categorical CrossentropyThe loss is masked to ignore contributions from padded tokens (value 0).Accuracy: Calculated as the percentage of non-padded tokens correctly predicted.🛠️ Usage ExampleTo run the training pipeline, ensure all Python files (3-dataset.py, 4-create_masks.py, 5-transformer.py, and 5-train.py) are in the same directory.Bash# Example command using parameters from the assignment:
